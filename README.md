# PetShop Amigo Fiel — Projeto Fundamentos de Sistemas Web (Fase 1)

Este repositório contém o código-fonte do sistema web do **PetShop Amigo Fiel**, desenvolvido para a **Fase 1** do Projeto da Disciplina *Fundamentos de Sistemas Web* (PUCRS).

## Objetivo

Construir a estrutura inicial de uma plataforma online para comércio de produtos e contratação de serviços de um petshop, utilizando exclusivamente **HTML5 semântico** (sem CSS, Bootstrap ou JavaScript, conforme especificado para a Fase 1).

## Funcionalidades das Páginas Web (Arquivo de Ajuda)

O sistema é composto por quatro páginas interligadas por um menu de navegação consistente no cabeçalho (`<header>`) e no rodapé (`<footer>`):

1. **`index.html` (Página Inicial):**
   - Apresentação do PetShop Amigo Fiel, endereço, telefone e horário de atendimento.
   - Visão geral das três categorias de produtos com links diretos para cada seção.
   - Destaque para os serviços de Banho e Tosa com e sem tele-busca.

2. **`produtos.html` (Catálogo de Produtos):**
   - Menu interno com âncoras para navegação rápida entre as categorias.
   - **Acessórios:** Cama Pet Confortável (Tamanho M) e Brinquedo Mordedor de Corda com Bola.
   - **Rações Não Perecíveis:** Ração Seca Premium para Cães Adultos (15 kg) e Ração Seca para Gatos Castrados Sabor Salmão (10 kg).
   - **Higiene e Limpeza:** Tapete Higiênico Super Absorvente (30 unidades) e Fralda Descartável Higiênica para Cães (12 unidades).
   - Cada produto exibe imagem ilustrativa, descrição detalhada e valor.

3. **`servicos.html` (Serviços de Banho e Tosa):**
   - Detalhamento dos serviços de **Banho Completo** e **Banho e Tosa Completa**, nas modalidades **Sem Tele-busca** e **Com Tele-busca**.
   - Tabela comparativa de valores por porte (pequeno e médio/grande).

4. **`ajuda.html` (Ajuda):**
   - Guia explicativo sobre a estrutura (cabeçalho, corpo e rodapé) e as funcionalidades de cada página do sistema web.
